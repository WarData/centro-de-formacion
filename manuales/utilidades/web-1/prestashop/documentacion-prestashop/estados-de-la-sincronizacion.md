# Estados de la sincronización

Los siguientes estados permiten conocer en todo momento la situación de la sincronización de un artículo entre Winmotor y la web. De esta forma, se puede comprobar si el artículo ya existe en la web (verificación), si está disponible para su alta o si se ha producido algún error durante el proceso de verificación o alta.

| Estado                                       | Cuándo se produce                                                                                                                                                                                                                 | Significado                                                                                                                                                                                                                                                                            |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Incidencia sin ref.**                      | `#REF` está vacío                                                                                                                                                                                                                 | El artículo no tiene referencia en WMT, por lo que no se puede buscar ni sincronizar en Prestashop.                                                                                                                                                                                    |
| **Error comunicación**                       | La API devuelve `STATUS >= 400`                                                                                                                                                                                                   | No se ha podido comprobar correctamente el artículo en la web por un error de comunicación/API. No debe confundirse con que el producto no exista.                                                                                                                                     |
| **Incidencia**                               | El `SKU`/`SKU_HIJ` guardado ya no existe en Prestashop                                                                                                                                                                            | WMT tenía guardado un ID de producto/combinación, pero ese elemento ya no existe en la web. Requiere revisión manual.                                                                                                                                                                  |
| **Enlazado**                                 | El ID existe y la referencia coincide                                                                                                                                                                                             | WMT y Prestashop están correctamente enlazados. En hijos también se comprueba que la combinación pertenece al producto padre esperado.                                                                                                                                                 |
| **Incidencia padre**                         | El hijo existe, pero pertenece a otro producto padre                                                                                                                                                                              | La combinación encontrada tiene la referencia correcta, pero su `id_product` no coincide con el `SKU` del padre almacenado en WMT.                                                                                                                                                     |
| **Incidencia padre-combinación**             | La combinación existe en la web colgando de un `id_product`, pero ese producto ya no existe, o su referencia no coincide con la del padre esperado en WMT (se detecta al intentar autocompletar el SKU del padre por primera vez) | El id\_product que devuelve la combinación no corresponde de forma verificable al padre que WMT cree tener. No se enlaza nada en falso; requiere revisión manual.                                                                                                                      |
| **Incidencia padre inválido**                | El padre en WMT tenía un SKU guardado, pero al comprobarlo por ID antes de dar de alta una combinación nueva, ese SKU ya no existe en Prestashop (404, respuesta vacía, o referencia no coincide)                                 | El SKU del padre estaba obsoleto. El proceso lo limpia automáticamente (`SKU=""`) para que se redetecte como "padre no existe en web" en la siguiente pasada. Es una incidencia auto-corregible: no requiere que alguien toque el dato, solo que se vuelva a ejecutar la verificación. |
| **Pendiente padre**                          | El artículo es un hijo/variación, no existe todavía como combinación en la web, y el padre en WMT **ni siquiera tiene SKU** (no está creado en la web)                                                                            | No se puede dar de alta esta combinación porque antes hay que crear el producto padre en Prestashop. No es un error: es una espera legítima hasta que el padre se sincronice.                                                                                                          |
| **Incidencia hijo**                          | El artículo hijo NO tiene color o talla                                                                                                                                                                                           | La combinación para poder crearse debe tener configurada al menos una talla o un color (Con nombre). Aunque Prestashop deje crear artículos sin valor de atributo lo recomendable es no crearlo si no está bien configurado en WMT.                                                    |
| **Incidencia ref.**                          | El ID existe, pero la referencia no coincide                                                                                                                                                                                      | El ID guardado apunta a un producto/combinación que ahora tiene otra referencia en Prestashop. Se considera un conflicto y no se modifica automáticamente.                                                                                                                             |
| **Incidencia dup.**                          | La referencia aparece más de una vez en Prestashop                                                                                                                                                                                | No se puede determinar automáticamente cuál de los productos/combinaciones es el correcto. Requiere revisión manual.                                                                                                                                                                   |
| **Incidencia tipo**                          | El artículo existe en Prestashop pero con otro tipo                                                                                                                                                                               | Por ejemplo, WMT lo considera **simple** pero en Prestashop aparece como **combinación**, o al contrario. No es apto para alta automática.                                                                                                                                             |
| **Incidencia tipo+dup.**                     | Existe con el tipo incorrecto y además varias veces                                                                                                                                                                               | La referencia aparece varias veces en Prestashop y, además, con un tipo diferente al que corresponde según WMT. Requiere revisión manual.                                                                                                                                              |
| **No sincronizado (no existe en web)**       | Producto **simple** no encontrado ni como `product` ni como `combination`                                                                                                                                                         | Es un producto que todavía no existe en Prestashop y queda **apto para alta automática**.                                                                                                                                                                                              |
| **No sincronizado (padre no existe en web)** | Artículo **padre** no encontrado en Prestashop                                                                                                                                                                                    | El padre de una variable todavía no existe en Prestashop. El proceso lo considera apto para crear automáticamente el padre y sus hijos.                                                                                                                                                |
| **No sincronizado**                          | Artículo **hijo/variación** no encontrado como combinación ni como producto                                                                                                                                                       | La combinación todavía no existe en Prestashop. Queda pendiente de alta, siempre que el padre ya esté enlazado (`SKU`).                                                                                                                                                                |

### Agrupados por situación

#### ✅ Correctamente sincronizado

* Enlazado

#### 🟡 Pendiente de sincronizar / alta

* No sincronizado (no existe en web) → producto simple
* No sincronizado (padre no existe en web) → padre de variable
* No sincronizado → hijo/variación
* Pendiente padre → hijo/variación cuyo padre aún no está creado en la web (a diferencia de "No sincronizado", que es cuando el padre sí existe pero al hijo le falta crearse)

#### 🔴 Requiere revisión

* Incidencia sin ref.
* Incidencia
* Incidencia padre
* Incidencia hijo
* Incidencia ref.
* Incidencia dup.
* Incidencia tipo
* Incidencia tipo+dup.
* Incidencia padre-combinación
* Incidencia padre inválido (con la matización de que, a diferencia de Error comunicación, aquí el proceso ya limpia el dato inconsistente por su cuenta; solo falta la reejecución para que se resuelva sola)

#### 🟠 Problema técnico temporal

* Error comunicación
